I'm a software engineer from Sousse, Tunisia, who likes owning a feature from the first commit to the production deploy. At **DecliTech** I build and run the company's web applications, and I teach learners aged 7 to 17 how to build robots, games, apps and AI projects.

- 🔭 **Now:** shipping features, handling production deployments and building internal tools
- ☁️ **Next:** cloud and DevOps engineering (AWS SAA, then CKA and Terraform Associate)
- 🎓 **Background:** Computer Science engineering degree with highest honors, École Polytechnique de Sousse
- 🌍 **Languages:** Arabic, French, English
